# Запуск «Алхимического котла» на Windows

Инструкция рассчитана на человека, который никогда не запускал программы из
командной строки. Читайте по порядку и не пропускайте шаги: каждый следующий
опирается на предыдущий.

Путей два:

- **Быстрый (Часть 1).** Готовая программа `Alchemy.exe`. Ничего устанавливать
  не нужно, 3–5 минут.
- **Из исходников (Части 2 и 3).** Нужны Python и три команды. Только если
  хотите менять код или собирать самому.

Локальная сеть настраивается одинаково для обоих путей — это Часть 4.

| Часть | О чём |
| --- | --- |
| 1 | Готовая сборка `.exe`: скачать, распаковать, запустить |
| 2 | Из исходников: установить Python, получить папку с проектом |
| 3 | Из исходников: venv, установка Flask, запуск |
| 4 | Локальная сеть через роутер: телефон и другие устройства |

---

## Часть 0. Что должно получиться

После всех шагов на вашем ноутбуке будет работающий сайт-калькулятор:

- на самом ноутбуке он открывается по адресу `http://127.0.0.1:8000`
- на телефоне в той же Wi-Fi сети — по адресу вида `http://192.168.1.57:8000`

Пока чёрное окно программы открыто, сайт работает. Закрыли окно — сайт
выключился. Это нормально: это не служба Windows, а обычная программа,
запущенная вручную.


Словарь терминов, которые встретятся дальше:

| Слово | Что это простыми словами |
| --- | --- |
| Терминал (PowerShell) | Чёрное окно, в которое вводят текстовые команды вместо нажатия кнопок |
| Команда | Строка текста, которую вставляют в терминал и подтверждают клавишей Enter |
| Python | Язык программирования и программа, которая исполняет код на этом языке |
| Виртуальное окружение (venv) | Личная папка с библиотеками проекта, чтобы не мусорить в системе |
| Библиотека | Готовый чужой код, который проект использует (здесь — Flask) |
| Flask | Библиотека, превращающая Python-код в веб-сайт |
| IP-адрес | Номер устройства в сети, например `192.168.1.57` |
| Порт | Номер «двери» на устройстве, здесь `8000`. Адрес с портом пишут так: `192.168.1.57:8000` |
| Роутер | Коробка, раздающая Wi-Fi и соединяющая устройства в одну сеть |

## Часть 1. Быстрый путь: готовый Alchemy.exe

Python, терминал и команды не нужны. Программа уже собрана и лежит в релизе.

### Шаг 1. Скачать архив

Откройте ссылку — скачивание начнётся сразу, без страниц и регистрации:

```
https://github.com/Slitock/Alchemestry_calculator/releases/latest/download/Alchemy-windows-x64.zip
```

Файл называется `Alchemy-windows-x64.zip`, весит около 14 МБ (точный размер
немного меняется от версии к версии). Windows сохранит его в папку «Загрузки».

### Шаг 2. Распаковать

1. Правый клик по архиву → **Извлечь все**.
2. В поле пути напишите `C:\Projects` → **Извлечь**.
3. Появится папка `C:\Projects\Alchemy`. Внутри: `Alchemy.exe`, папка
   `_internal` и, после первого запуска, папка `data`.

Две ошибки, которые ломают запуск:

- запуск `Alchemy.exe` прямо из окна архива — программа не найдёт свои файлы;
- распаковка в `OneDrive` — синхронизация мешает записи базы данных.

### Шаг 3. Запустить

Двойной клик по `Alchemy.exe`. Откроется чёрное окно с адресами:

```
=== Алхимический котёл: сервер запущен ===
  На этом ноутбуке:  http://127.0.0.1:8000
  В локальной сети:  http://192.168.1.57:8000
```

Окно не закрывайте: пока оно открыто — сайт работает.

Если появилось синее окно **«Windows защитила ваш компьютер»**, нажмите
**Подробнее** → **Выполнить в любом случае**. Так Windows встречает любой
файл без платной цифровой подписи, это не признак вируса.

### Шаг 4. Открыть сайт

В браузере на этом же ноутбуке: `http://127.0.0.1:8000`

### Шаг 5. Разрешить доступ в брандмауэре

При первом запуске Windows спросит:

> **Брандмауэр Защитника Windows заблокировал некоторые функции этого
> приложения**

Нажмите **Разрешить доступ**, отметьте **Частные сети**, галочку
**Общедоступные сети** не ставьте, нажмите **OK**. Подробнее — шаг 10
в Части 3, там же команда на случай, если окно закрыли случайно.

### Где лежат данные и как обновляться

- База: `C:\Projects\Alchemy\data\alchemy.db` — рядом с `.exe`, а не внутри
  программы. Правки из админки сохраняются между запусками.
- Удалить папку `data` — база создастся заново с исходными ингредиентами.
- Перенести на другой компьютер — скопируйте всю папку `Alchemy` целиком.
- Обновиться на новую версию — распакуйте новый архив в новую папку и
  перенесите туда `data` из старой.

Дальше сразу переходите к Части 4 (локальная сеть). Части 2 и 3 нужны, только
если хотите запускать из исходников.

## Часть 2. Подготовка: установка Python

### Шаг 1. Установить Python

1. Откройте в браузере <https://www.python.org/downloads/windows/>.
2. Нажмите большую жёлтую кнопку **Download Python 3.x.x** (любая версия не
   ниже 3.12 — проект требует минимум 3.10).
3. Запустите скачанный файл `python-3.x.x-amd64.exe`.
4. **Самый важный момент:** в первом окне установщика поставьте галочку
   **Add python.exe to PATH** (внизу списка). Без неё Windows не найдёт Python,
   и команды из инструкции выдадут ошибку.
5. Нажмите **Install Now**, дождитесь надписи **Setup was successful**, закройте
   установщик.

Проверка. Нажмите `Win + R`, введите `cmd`, нажмите Enter. В чёрном окне
наберите:

```bat
py --version
```

Должно появиться что-то вроде `Python 3.13.5`. Если вместо этого написано
«py не является внутренней или внешней командой», Python не установился
или установился без галочки PATH — переустановите, отметив галочку.

> Если `py --version` открывает Microsoft Store вместо вывода версии, значит
> установлен только «ярлык» из магазина. Скачайте установщик с python.org и
> повторите шаг 1.

### Шаг 2. Скачать проект

Проект открыт: регистрация на GitHub не нужна, достаточно браузера. Ниже —
версия последнего релиза (`v1.0.1`). Если на странице релизов уже есть более
новая, берите её.

**Вариант А — одна ссылка (проще всего).** Откройте в браузере:

```
https://github.com/Slitock/Alchemestry_calculator/archive/refs/tags/v1.0.1.zip
```

Скачивание начнётся сразу, без переходов по страницам. Windows сохранит архив
в папку «Загрузки».

**Вариант Б — через страницу релиза.** Откройте
<https://github.com/Slitock/Alchemestry_calculator/releases/latest>, прокрутите
до раздела **Assets** и нажмите **Source code (zip)**. Это тот же архив.

**Вариант В — через git (для тех, у кого установлен Git).** В терминале:

```powershell
git clone --branch v1.0.1 https://github.com/Slitock/Alchemestry_calculator.git alchemestry
```

Флаг `--branch v1.0.1` скачивает именно версию из релиза, а не текущее
состояние ветки.

### Шаг 3. Положить проект в простое место

1. Создайте папку `C:\Projects` (или любую другую с коротким путём).
2. Распакуйте скачанный архив: правый клик по файлу → «Извлечь все» →
   в поле пути укажите `C:\Projects` → «Извлечь».
3. Внутри появится папка `Alchemestry_calculator-1.0.1`. Переименуйте её
   в `alchemestry`. Должно получиться `C:\Projects\alchemestry`.

Почему именно так:

- путь без пробелов и кириллицы избавляет от половины непонятных ошибок;
- не кладите проект в `Downloads`, `Desktop` или `OneDrive` — OneDrive
  синхронизирует файлы и иногда блокирует базу данных.

Внутри папки должны лежать файлы `app.py`, `main.py`, `requirements.txt`
и папки `web`, `core`, `database`, `docs`. Если после распаковки вы видите
одну единственную папку с таким же названием внутри — Windows создал лишний
уровень, зайдите на уровень глубже и работайте там.

## Часть 3. Запуск из исходников

### Шаг 4. Открыть терминал в папке проекта

1. Откройте проводник и зайдите в `C:\Projects\alchemestry`.
2. Щёлкните по адресной строке проводника (там, где написан путь).
3. Напишите `powershell` и нажмите Enter.

Откроется синее (или чёрное) окно **PowerShell**. В нём строка приглашения
начинается с `PS C:\Projects\alchemestry>`. Это значит, что все команды будут
выполняться внутри папки проекта — именно то, что нужно.

> Проверка на всякий случай: введите `ls` и Enter. Должен появиться список с
> `app.py`, `requirements.txt` и папками `web`, `database`.

### Шаг 5. Проверить Python в этом окне

```powershell
py --version
```

Ожидаемо: `Python 3.13.5` (номер может отличаться). Если ошибка — вернитесь
к шагу 1.

### Шаг 6. Создать виртуальное окружение

Скопируйте строку целиком, вставьте в терминал (правый клик мышью или
`Ctrl + V`) и нажмите Enter:

```powershell
py -m venv .venv
```

Появится новая папка `.venv` (в проводнике она может быть скрыта — это
нормально). Внутри неё будет отдельная копия Python для этого проекта.

Зачем: библиотеки проекта не смешаются с другими программами, а удалить
всё лишнее можно, просто стерев папку `.venv`.

### Шаг 7. Установить библиотеку Flask

```powershell
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
```

Что происходит: `pip` — установщик библиотек, `-r requirements.txt` — «возьми
список нужного из файла». В списке один пункт — `Flask`. Установка идёт из
интернета, поэтому нужна сеть и 1–2 минуты.

Успех выглядит так: в конце написано `Successfully installed Flask-3.x.x ...`
и снова появилось приглашение `PS C:\Projects\alchemestry>`.

> Не активируйте виртуальное окружение через `Activate.ps1` — в Windows это
> часто упирается в запрет на выполнение скриптов. Команды выше обращаются к
> `.venv` напрямую, поэтому активация не нужна вообще.

### Шаг 8. Запустить сервер

```powershell
.\.venv\Scripts\python.exe app.py
```

Через пару секунд в окне появится примерно это:

```
=== Алхимический котёл: сервер запущен ===
  На этом ноутбуке:  http://127.0.0.1:8000
  В локальной сети:  http://192.168.1.57:8000
  Админка:           http://127.0.0.1:8000/admin
  База данных:       C:\Projects\alchemestry\data\alchemy.db
  Остановка: Ctrl+C
 * Running on all addresses (0.0.0.0)
```

Терминал теперь занят: он показывает логи запросов, и вводить в него команды
больше нельзя. Это нормально.

- Первая строка `В локальной сети` — это адрес для телефона. Запишите его.
- Файл базы `data/alchemy.db` создаётся автоматически при первом запуске,
  отдельно ничего создавать не нужно.
- Если строка «В локальной сети» отсутствует — значит ноутбук сейчас не
  подключён к Wi-Fi или кабелю. Сайт на самом ноутбуке всё равно работает.

### Шаг 9. Открыть сайт

В браузере на этом же ноутбуке откройте:

```
http://127.0.0.1:8000
```

Должен появиться котёл с ингредиентами. Проверка логики: положите два
ингредиента и нажмите «Сварить» — справа появится результат и инструкция.

Админка, где правят ингредиенты: `http://127.0.0.1:8000/admin`.

### Шаг 10. Разрешить доступ в брандмауэре Windows

При первом запуске Windows почти наверняка покажет окно:

> **Брандмауэр Защитника Windows заблокировал некоторые функции этого
> приложения**

1. Нажмите **Разрешить доступ**.
2. Отметьте галочку **Частные сети** (Private networks).
3. Галочку **Общедоступные сети** (Public networks) **не** ставьте: в кафе и
   аэропортах это открыло бы ваш сайт посторонним.
4. Нажмите **OK**.

Если окно закрыли случайно, доступ можно выдать вручную. Откройте PowerShell
**от имени администратора** (правый клик по «Пуск» → «Терминал (администратор)»)
и выполните одной строкой:

```powershell
New-NetFirewallRule -DisplayName "Alchemy 8000" -Direction Inbound -Protocol TCP -LocalPort 8000 -Action Allow -Profile Private
```

Отдельно проверьте, что сеть считается «частной»: **Параметры → Сеть и
интернет → Wi-Fi → свойства сети → тип профиля сети → Частная**. Если стоит
«Общедоступная», Windows блокирует входящие подключения, и телефон не сможет
открыть сайт.

### Как выключать и включать снова

Выключить: щёлкните по окну терминала и нажмите `Ctrl + C`. Появится
приглашение `PS C:\...>` — сервер остановлен, порт освобождён.

Включить в следующий раз (устанавливать ничего не надо):

1. Проводник → `C:\Projects\alchemestry` → щёлкнуть по адресной строке →
   `powershell` → Enter.
2. Одна команда:

```powershell
.\.venv\Scripts\python.exe app.py
```

3. Открыть `http://127.0.0.1:8000`.

Если удобнее двумя кликами, позже можно добавить файл `start-windows.bat`
с этой командой — но это отдельное улучшение, для первого запуска не нужно.

## Часть 4. Локальная сеть: как открыть сайт с телефона

### Как это устроено

Сервер запускается на ноутбуке и слушает адрес `0.0.0.0:8000`. Это значит
«принимай подключения на всех сетевых интерфейсах», а не только с самого
ноутбука. Каждое устройство в домашней сети получило от роутера свой номер
(IP-адрес), и телефон обращается по номеру ноутбука.

```
                 +----------------------------+
                 |          РОУТЕР            |
                 |  адрес в сети: 192.168.1.1 |
                 |  раздаёт IP: 192.168.1.x   |
                 +------+--------------+------+
                        |              |
             Wi-Fi / кабель           Wi-Fi
                        |              |
        +---------------+--+      +----+-------------------+
        |  НОУТБУК          |      |  ТЕЛЕФОН / ПЛАНШЕТ  |
        |  IP 192.168.1.57  |      |  IP 192.168.1.34    |
        |  запущен app.py   |      |  браузер            |
        |  порт 8000        |      |                     |
        +-------------------+      +---------------------+

        телефон открывает: http://192.168.1.57:8000
```

Ключевое правило: **все устройства должны быть в одной сети**, то есть
подключены к одному роутеру (или к одной и той же Wi-Fi сети этого роутера,
включая случаи, когда 2,4 ГГц и 5 ГГц называются по-разному).

### Сценарий по шагам

**Шаг 1. Подключите ноутбук к роутеру.** Wi-Fi или кабель — без разницы.
Убедитесь, что интернет на ноутбуке работает (сайту интернет не нужен, но так
проще понять, что сеть жива).

**Шаг 2. Узнайте IP-адрес ноутбука.** В новом окне PowerShell (не в том, где
работает сервер) выполните:

```powershell
ipconfig
```

Найдите раздел вашего подключения — «Адаптер беспроводной локальной сети
Wi-Fi» или «Адаптер Ethernet» — и строку **IPv4-адрес**. Например:

```
IPv4-адрес . . . . . . . . . . : 192.168.1.57
```

Адреса `192.168.*.*` и `10.*.*.*` — обычные домашние. Если вы видите
`169.254.*.*`, ноутбук не получил адрес от роутера: переподключитесь к Wi-Fi.

**Шаг 3. Запустите сервер** (шаг 8 в Части 3, либо шаг 3 в Части 1) и посмотрите
на строку «В локальной сети». Она должна совпасть с адресом из `ipconfig`.

**Шаг 4. Выдайте доступ в брандмауэре** (шаг 10 в Части 3 или шаг 5 в
Части 1). Без этого шага телефон увидит «сайт недоступен», даже если всё
остальное настроено.

**Шаг 5. Подключите телефон к той же Wi-Fi сети.** Именно к той же, что и
ноутбук. Проверить: на телефоне в настройках Wi-Fi имя сети должно совпадать
с именем сети ноутбука.

**Шаг 6. Откройте на телефоне браузер** и введите адрес с портом:

```
http://192.168.1.57:8000
```

Три типичные ошибки при вводе:

- забыли `http://` — телефон может подставить поиск в Google;
- забыли `:8000` — браузер пойдёт на порт 80, где ничего нет;
- ввели `127.0.0.1` — этот адрес всегда означает «это же устройство», то есть
  на телефоне он указывает на сам телефон, а не на ноутбук.

**Шаг 7. Проверьте, что всё работает.** На телефоне должна открыться та же
страница с котлом. Котёл у каждого свой: состав хранится в браузере устройства,
поэтому телефон и ноутбук не мешают друг другу. Ингредиенты и рецепты общие —
они в базе на ноутбуке. Правки в админке сразу видны на всех устройствах.

### Что настроить в роутере

Настройки роутера открываются в браузере по адресу самого роутера — обычно
`http://192.168.1.1` или `http://192.168.0.1` (точный адрес написан на наклейке
снизу корпуса, там же логин и пароль, часто `admin` / `admin`).

Три вещи, которые стоит проверить:

1. **Изоляция клиентов выключена.** Называется `AP isolation`, `Client
   isolation`, «Изоляция клиентов», «Запретить обмен между устройствами».
   Если она включена, устройства видят роутер, но не видят друг друга —
   телефон не откроет сайт ноутбука. Выключите и сохраните настройки.
2. **Гостевая сеть не используется.** Гостевая Wi-Fi сеть (`Guest network`)
   по замыслу изолирована от основной. Подключайте телефон к основной сети.
3. **Адрес ноутбука не меняется.** Роутер выдаёт адреса по DHCP и теоретически
   может завтра выдать другой. Два способа закрепить:
   - в разделе `DHCP` → `Address Reservation` / «Резервирование адресов»
     привязать IP `192.168.1.57` к MAC-адресу ноутбука (MAC виден в
     `ipconfig` как «Физический адрес»);
   - либо задать ноутбуку статический IP в настройках Windows, но это менее
     удобно: легко ошибиться и потерять связь с роутером.

   Это не обязательно для первого запуска: просто сверяйтесь с `ipconfig`,
   если адрес изменился.

Больше ничего в роутере трогать не нужно. **Проброс портов (port forwarding)
делать не надо** — он открыл бы сайт в интернет, а нам нужна только домашняя
сеть.

### Проверка соединения, если что-то не работает

Порядок проверок — от простого к сложному.

1. С другого компьютера в той же сети (не телефона) проверьте доступность
   ноутбука:

   ```powershell
   ping 192.168.1.57
   Test-NetConnection -ComputerName 192.168.1.57 -Port 8000
   ```

   - `ping` не проходит → проблема в сети или в изоляции клиентов на роутере,
     дело не в приложении.
   - `ping` проходит, а `TcpTestSucceeded : False` → пакеты доходят, но порт
     закрыт: почти всегда это брандмауэр Windows (шаг 10 в Части 3) или сервер не
     запущен.
   - `TcpTestSucceeded : True` → сеть в порядке, проблема в браузере телефона
     (опечатка в адресе).

2. На ноутбуке проверьте, что сервер действительно слушает:

   ```powershell
   netstat -ano | findstr :8000
   ```

   В ответе должна быть строка `TCP 0.0.0.0:8000 ... LISTENING` с номером
   процесса в конце. Пустой ответ — сервер не запущен или упал, смотрите
   сообщение об ошибке в окне с `app.py`.

3. Проверьте профиль сети Windows: он должен быть «Частная». В «Общедоступной»
   Windows блокирует входящие подключения независимо от правил.

4. Временно проверьте без брандмауэра, чтобы точно его опознать:

   ```powershell
   Set-NetFirewallProfile -Profile Domain,Private,Public -Enabled False
   ```

   Если после этого телефон открыл страницу — виноват брандмауэр, включите его
   обратно (`-Enabled True`) и добавьте правило из шага 10. Не оставляйте
   брандмауэр выключенным.

### Таблица типичных причин

| Симптом | Вероятная причина | Что делать |
| --- | --- | --- |
| На ноутбуке сайт открывается, на телефоне «не удаётся получить доступ к сайту» | Брандмауэр или профиль «Общедоступная» | Шаг 10, затем частная сеть |
| Телефон вообще не видит ноутбук по IP | Разные сети, гостевая сеть или изоляция клиентов | Одна Wi-Fi сеть, выключить AP isolation |
| Вчера работало, сегодня адрес не открывается | Роутер выдал ноутбуку другой IP | Сверьте `ipconfig`, закрепите адрес в DHCP |
| Страница грузится, кнопка «Сварить» даёт ошибку | Сервер упал или перезапускается | Смотрите окно с `app.py` |
| Телефон открывает чужой сайт или поиск | Пропущено `http://` или `:8000` | Ввести адрес полностью |
| Ноутбук «уснул» — телефон перестал открывать сайт | Спящий режим отключает Wi-Fi | Питание → не отключать Wi-Fi в спящем режиме, либо не давать ноутбуку спать при подключённом питании |

### Вариант без роутера: мобильный хот-спот

Если роутера нет или он изолирует устройства:

- **Хот-спот с телефона.** Включите на телефоне «Точка доступа», подключите
  ноутбук к этой Wi-Fi сети. Дальше всё как обычно: `ipconfig` на ноутбуке
  покажет адрес, остальные устройства (ещё один телефон) подключаются к той же
  точке доступа и открывают `http://<адрес ноутбука>:8000`.
- **Хот-спот с ноутбука.** Windows: Параметры → Сеть и интернет → Мобильный
  хот-спот → включить. Ноутбук обычно становится адресом `192.168.137.1`,
  и сайт доступен по `http://192.168.137.1:8000` с подключённых устройств.

### Безопасность, о которой важно знать

- Сервер работает по `HTTP` без шифрования. Пароли и данные в такой сети
  видны любому, кто умеет слушать трафик. Для домашней игры это приемлемо,
  для общежития или коворкинга — нет.
- Админка `/admin` по умолчанию открыта всем в сети. Если в сети есть
  посторонние, включите пароль — в PowerShell перед запуском:

  ```powershell
  $env:ALCHEMY_ADMIN_PASSWORD = "ваш-пароль"
  .\.venv\Scripts\python.exe app.py
  ```

  Логин по умолчанию `admin`. Пароль действует только в этом окне: закрыли
  терминал — сбросился.
- Не настраивайте проброс порта 8000 на роутере и не выставляйте ноутбук в
  DMZ. Сайт должен быть доступен только внутри дома.

## Частые ошибки Windows и их лечение

### Если запускаете Alchemy.exe

**«Windows защитила ваш компьютер» при запуске.**
Файл без платной цифровой подписи, это обычное дело: **Подробнее** →
**Выполнить в любом случае**. Если кнопки нет — правый клик по `Alchemy.exe`
→ **Свойства** → внизу галочка **Разблокировать** → **ОК**.

**Чёрное окно открывается и сразу закрывается.**
Почти всегда причина одна: `.exe` запущен из архива или архив распакован не
полностью. Распакуйте заново через «Извлечь все» в обычную папку (не в
`OneDrive`, не в «Загрузки» с длинным путём) и запустите `Alchemy.exe` из неё.

**Антивирус удалил `Alchemy.exe`.**
Сборка без подписи, эвристика иногда ругается. Добавьте папку `Alchemy`
в исключения антивируса. Если не доверяете чужой сборке — соберите сами:
исходники открыты, команда сборки в `README.md`.

**Сайт открывается, но без картинок и стилей.**
Проверьте, что рядом с `Alchemy.exe` есть папка `_internal`. Если её нет —
архив распакован частично, распакуйте заново.

**Правки из админки пропали после перезапуска.**
Проверьте, что папка `data` лежит рядом с `Alchemy.exe` и не удаляется.
Если запускать `.exe` из другой папки, каждый раз будет новая пустая база.

### Если запускаете из исходников

**`py` не является внутренней или внешней командой.**
Python не в PATH. Переустановите с галочкой **Add python.exe to PATH** или
используйте `python` вместо `py`.

**`python` открывает Microsoft Store.**
Это заглушка Windows. Установите Python с python.org, используйте `py`.

**`Невозможно загрузить файл ...Activate.ps1, так как выполнение сценариев
отключено в этой системе`.**
Вы пытаетесь активировать окружение. В этой инструкции активация не нужна:
вызывайте `.\.venv\Scripts\python.exe` напрямую. Если очень хочется активировать,
разрешите скрипты только для текущего окна:
`Set-ExecutionPolicy -Scope Process Bypass`.

**`pip не является внутренней или внешней командой`.**
Используйте полный путь: `.\.venv\Scripts\python.exe -m pip ...`.

**`error: [Errno 10048] ... address already in use` / порт занят.**
Кто-то уже слушает 8000. Найдите его и завершите:

```powershell
netstat -ano | findstr :8000
taskkill /PID <номер-из-последнего-столбца> /F
```

Либо запустите на другом порту (тогда его же открывайте в браузере):

```powershell
$env:ALCHEMY_PORT = "8080"
.\.venv\Scripts\python.exe app.py
```

**`SyntaxError` при запуске `app.py`.**
Слишком старый Python. Проверьте `py --version`: нужно 3.10 или новее.

**`ModuleNotFoundError: No module named 'flask'`.**
Не выполнен шаг 7 или команда запускается не тем Python. Убедитесь, что
запускаете `.\.venv\Scripts\python.exe`, а не просто `python`.

**`Кодировка`/кракозябры вместо русских букв в логах.**
Косметика консоли, на работу сайта не влияет. Можно выполнить
`chcp 65001` в том же окне до запуска.

## Шпаргалка: всё нужное в одном месте

Готовая сборка (ничего устанавливать не нужно):

```text
1. Скачать: https://github.com/Slitock/Alchemestry_calculator/releases/latest/download/Alchemy-windows-x64.zip
2. Распаковать в C:\Projects
3. Запустить C:\Projects\Alchemy\Alchemy.exe
   (первый запуск: разрешить доступ, галочка «Частные сети»)
4. Открыть http://127.0.0.1:8000
```

Из исходников, первый запуск (один раз):

```powershell
cd C:\Projects\alchemestry
py -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
```

Запуск из исходников, каждый раз:

```powershell
cd C:\Projects\alchemestry
.\.venv\Scripts\python.exe app.py
```

Адреса:

- на ноутбуке — `http://127.0.0.1:8000`
- админка — `http://127.0.0.1:8000/admin`
- на телефоне — `http://<IP-ноутбука>:8000`, IP берётся из `ipconfig` или из
  строки «В локальной сети» при запуске

Остановка: `Ctrl + C` в окне терминала, либо просто закрыть чёрное окно
программы.
